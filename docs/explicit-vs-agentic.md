auto-approved. 3 question(s) x 2 repeat(s), generated by `scripts/compare_workflows.py`.

1. What orchestration patterns do LLM-based multi-agent systems use, and how do they trade off control, cost and robustness?
2. How do multi-agent LLM systems decide which agent acts next, and what does each approach cost?
3. What communication topologies do LLM agent teams use, and how does topology affect task performance?

- **citation score**: share of cited sentences the CitationCheckWorkflow finds no problem with, re-checked
  the same way for both drafts (deterministic checks + Haiku judge).

  (1.0 = identical outline): a rough determinism measure.
- **orchestration LOC**: code lines (no blanks, comments, docstrings) of `workflows/review.py` vs
  `workflows/agent_review.py`. Shared code (retrieval, check, render) is not counted for either.
